## 6. Design decisions per chart type

- **Bar chart (track counts):** Spotify Green `#1DB954` bars, no outlines, on
  Elevated Dark `#181818` over Spotify Black `#121212`; subtle `#333333` gridlines.
- **Two-series trend charts:** the "all years" context series is now Muted Grey
  `#B3B3B3` at 35% opacity (was faint steelblue); the reliable-years series is
  Spotify Green at 2 pt with small markers (was darkblue). Meaning unchanged:
  faint = years with fewer than 30 tracks.
- **Combined feature chart:** Energy = Spotify Green, Danceability = muted blue
  `#9DB8D2`, Valence = muted sand `#D3B078` — restrained complements so three
  series stay distinguishable without random colours; dark framed legend.
- **Typography:** Arial (locally installed), white bold 13 pt titles, muted-grey
  11 pt axis labels, 10 pt ticks; top/right spines removed; 0.8 pt charcoal borders.
- **Export:** 300 DPI, non-transparent `#121212` background, tight layout,
  unchanged 12×5 in figure size for comparability.
- **Future heatmaps:** `spotify_diverging` colormap (muted blue → charcoal zero →
  green) is provided so correlation heatmaps keep a meaningful zero midpoint.

## 9. How teammates apply the shared style to future charts

From the project root (consolidated notebook):

```python
from src.spotify_chart_style import apply_spotify_style, spotify_green
apply_spotify_style()   # once, before any chart
```

From a notebook inside a subfolder (e.g. `notebooks/`):

```python
import sys
sys.path.append('../src')
from spotify_chart_style import apply_spotify_style, spotify_green
apply_spotify_style()
```

Then write normal Matplotlib/Seaborn code. Useful constants:
`spotify_green`, `soft_green`, `muted_grey`, `muted_blue`, `muted_sand`,
`spotify_series` (default colour cycle), `spotify_diverging` (correlation
heatmaps: use with `center=0` and white annotations). `save_spotify_chart(path)`
applies tight layout and saves at 300 DPI with the dark background.

Rules of thumb: green for the primary series; muted grey/blue/sand only for extra
categories; keep gridlines subtle; never colour every element green.
